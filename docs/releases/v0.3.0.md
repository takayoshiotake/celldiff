出力先を省略して比較できるようになりました。

## 変更

- `-o`／`--output`を任意指定に変更。
- 省略時はカレントディレクトリの`diff.xlsx`へ出力。
- 明示指定した場合は、指定した出力先だけに保存。

## 使用例

```sh
# カレントディレクトリのdiff.xlsxへ出力
celldiff left.csv right.csv

# 出力先を指定
celldiff left.csv right.csv -o result.xlsx

# 既存のdiff.xlsxを明示的に上書き
celldiff left.csv right.csv --force
```

既存ファイルは自動で上書きしません。上書きには`--force`が必要です。
`--force`を指定しても、入力ファイルとその別名は保護します。
比較・保存の失敗時は既存出力を保持します。

`--list-encodings`、`--help`、`--version`では出力ファイルを生成しません。
文字コード指定、差分表示、終了コードは従来どおりです。
