Excelを開かずに差分セルを確認できるテキスト出力を追加しました。

## 追加

- `--text`で差分セルの一覧を標準出力に表示。Excelファイルは生成しません。
- `--oneline`で差分セル1つを1行で表示。
- `--address a1|rc`でセルアドレスの表記を選択。既定はA1表記、`rc`では行番号・列番号を表示します。

## 使用例

```sh
celldiff left.csv right.csv --text
celldiff left.csv right.csv --text --oneline
celldiff left.csv right.csv --text --oneline --address rc
```

```text
B2: "東京本社" -> "大阪本社"
D8: <missing> -> ""

Changed cells: 2 (modified=1, added=1, removed=0)
```

座標はCSVの論理レコード・列位置に対応します。空文字列と欠落を区別し、改行や制御文字はエスケープします。
差分なしの場合は`No differences.`と表示します。
文字コード指定と終了コード（0＝差分なし、1＝差分あり、2＝エラー）は従来どおりです。

## オプションの組み合わせ

`--oneline`と明示的な`--address`は`--text`専用です。
`--text`と`-o`／`--output`、`--force`、`--list-encodings`は併用できません。

テキスト出力にはExcel固有の行数・列数・セル文字数上限を適用しません。
一覧は逐次出力するため、途中のエラーでは部分的な一覧が残る場合があります。その場合は最終集計を表示せず、終了コード2で終了します。

`--text`を省略した場合のExcel出力は従来どおりです。
