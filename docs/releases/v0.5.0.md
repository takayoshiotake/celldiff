CSVフィールドを囲む引用符の有無も比較できるオプションを追加しました。

## 追加

- `--compare-quotes`で、解析後の値と引用符の有無を比較。
- `1`と`"1"`、空フィールドと`""`の違いを検出。
- 引用符だけの追加・削除もModifiedとして集計。

## 使用例

```sh
celldiff left.csv right.csv --compare-quotes
celldiff left.csv right.csv --compare-quotes --text --oneline
```

```text
A1: "1" [unquoted] -> "1" [quoted]

Changed cells: 1 (modified=1, added=0, removed=0)
```

テキスト出力では、存在するセルに`[quoted]`／`[unquoted]`を注記します。
Excelでは、オプション指定時に引用符付きフィールドをCSV表現で表示し、変更した引用符も文字単位で強調します。
変更のないセルもこの表示方法になりますが、元の行・列位置は維持します。Summaryには比較設定を記録します。

## 対応範囲

省略時は従来どおり、`1`と`"1"`を同じ値として扱います。
左右の文字コード指定、`--text`・`--oneline`・`--address`と併用できます。
BOM・改行コード・文字コードだけの違いを検出する生バイト比較ではありません。

Excelの文字数上限は引用符・エスケープを含む表示にも適用されます。
不正な入力や保存エラーが起きた場合の既存ファイル保護、終了コード0／1／2は従来どおりです。
