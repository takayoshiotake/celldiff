入力CSVの文字コードを左右それぞれ指定できるようになりました。

## 追加

- `--encoding-left`／`--encoding-right`で入力文字コードを指定（別名：`--el`／`--er`）。
- UTF-8、Shift_JIS系、UTF-16LE／BEなど38種類に対応。
- `--list-encodings`で対応する文字コード名と別名を一覧表示。
- Summaryシートに左右の使用文字コード名を記録。

## 使用例

```sh
celldiff left.csv right.csv --el cp932 --er utf-8 -o diff.xlsx
celldiff --list-encodings
```

省略した側は従来どおりUTF-8です。文字コードの自動検出は行いません。
不正なバイト列や指定と矛盾するBOMはエラーとし、置換文字への暗黙の置き換えは行いません。
`cp932`はencoding_rsのShift_JISマッピングを使用し、Windows CP932のすべての挙動と完全同一ではありません。

## 変更

- CLI・Summary・サンプルの入力名をleft／rightに統一。比較方向はleftからrightへの変更です。
- 比較方法、元の行・列位置を保持するExcel出力、終了コードは従来どおりです。

## 配布物

Windows x64、Linux x64、macOS Apple Silicon向けです。
各アーカイブには実行ファイルと`celldiff-build-info.txt`を同梱します。
アーカイブのSHA-256は別添の`checksums.txt`で確認できます。Rustランタイムは不要です。
