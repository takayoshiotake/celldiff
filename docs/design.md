# celldiff 設計

## 目的と対象

2つのCSVをセル単位で比較し、変更した文字を強調した.xlsxレポート、または差分セルのテキスト一覧を出力するCLI。
Rustで実装し、Windows・Linux・macOSへOS別の実行ファイルを配布する。
GUI、キー照合、行の再対応、マージ、TSV・Excel入力は初期版に含めない。

## 入力と対応づけ

入力はleft／rightと呼び、leftを基準としたrightへの変更を表示する。
leftだけにある文字・セルは削除、rightだけにある文字・セルは追加とする。

- 左右別々に文字コードを明示指定する。省略時はUTF-8。自動検出・共通指定は設けない。
- encoding_rsのWHATWGマッピングを使い、encodingモジュールの38種類と公開別名だけを受け付ける。
- DecodedReaderが固定サイズの入力・出力バッファでUTF-8へ逐次変換する。
- 置換なしのデコーダーを使い、不正なバイト列・末尾の不完全な文字はエラーとする。
- BOMは指定と一致する場合だけ除去する。不一致BOM・UTF-32 BOMはエラーとする。
- UTF-16LE／BEはBOMなしでも明示指定で扱う。UTF-32・曖昧なutf-16・autoは受け付けない。
- cp932／windows-31jはShift_JISへ対応付けるがWindows CP932の完全な互換実装とはしない。
- ascii／iso-8859-1／latin1はWHATWGに従いWindows-1252へ対応付ける。
- カンマ区切り。引用符、引用符内改行、エスケープはcsv crateに任せる。
- 独自の厳格なCSV構文検証は加えず、構文の許容範囲はcsv crateに従う。
- 先頭レコードもデータ。ヘッダーを自動検出・除外しない。
- 空の物理行はパーサーがスキップする。明示的な空フィールドは保持する。
- 可変フィールド数を許容する。
- 論理レコード番号・列番号は1始まり。物理行番号とは区別する。
- 同じレコード番号・列位置同士を比較する。途中への挿入や並べ替えの後も再対応しない。
- 片方がEOFになっても、長い側の残りを比較する。

`CsvInput<R: Read>`が読み込み元を所有し、呼び出し側の`StringRecord`を再利用する。
入力エラーは入力名と、取得可能なレコード・物理行・バイト位置、元のエラーを保持する。
バイト位置は変換後のUTF-8上の位置であり、元ファイルのバイトオフセットではない。

## セル比較

解析後の文字列を比較する。型変換、trim、大小文字統一、Unicode正規化を行わない。
`001`と`1`は異なる値。引用符などCSV記法だけの違いは差分にしない。

| 状態 | 種別 |
| --- | --- |
| 両方存在し値が異なる | Modified |
| 比較元に存在せず、比較先に存在する | Added |
| 比較元に存在し、比較先に存在しない | Removed |
| 両方存在し同じ値 | 元の位置に通常表示 |

存在する空文字列は`Some("")`、存在しないセルは`None`として区別する。
余剰レコードもセルごとにAdded／Removedを出す。空フィールドも件数に含む。
変更セル数は値または存在が違うセル数、変更レコード数は1つ以上の差分を持つ入力レコード数。
元・先の読み込みレコード数、種別別のセル数も集計する。

compare_allは同じセルも含む全セルを、元の座標とバッファ内の値を借用してコールバックへ渡す。
差分だけを通知するcompareも比較ロジックの検証用に維持する。
コールバックは次の入力前に処理を終える。全入力・全差分を蓄積しない。

## 文字差分

異なるセルにだけ`similar`の書記素クラスタ差分を適用する。
結合文字や絵文字を分断しない単位を選ぶ。正規化はしない。
共通・削除・追加を取り出し、隣接する同種区間を結合する。

1セルの差分に100msの計算時間目安を設定する。
ライブラリがタイムアウトすると対応が近似になる場合があり、最短・唯一の編集列は保証しない。
元・先の値の復元可能性は維持する。これはプロセス全体の厳密な時間制限ではない。
繰り返し文字列では対応が一意でないため、値の復元と安定した書式を検証する。

## Excel出力

元のCSVの行・列位置を保つ。第1レコード・第1フィールドはExcelのA1。
変更のない行・セルも出力し、説明用の見出し行やRecord/Column列を加えない。
初期の差分一覧方式は廃止した。表の位置関係が変わるため。

`Differences`シートの1セル内に、共通・削除・追加の文字区間を差分順に並べる。
共通部分は1回だけ表示する。削除は赤字・取り消し線、追加は青字・太字。
たとえば「東京本社→大阪本社」の表示文字列は「東京大阪本社」で、
「東京」を削除、「大阪」を追加として装飾する。
表示文字列そのものは変更前・変更後の生データではない。

| セルの状態 | 背景 |
| --- | --- |
| 変更なし | 通常 |
| 両側に存在して値が異なる | 薄い黄色 |
| 比較先だけに存在 | 薄い青 |
| 比較元だけに存在 | 薄い赤 |

存在する空値はセルを明示的に書き込み、追加・削除の空値も背景色で区別する。
Summaryに件数・入力・左右の使用文字コード名・凡例を記載し、表の行列を増やすメタデータは置かない。
差分がない場合も全入力セルとSummaryを出力する。

`rust_xlsxwriter`のconstant-memoryモードを使い、入力座標順に書き込む。
一度書いた行へ戻らない。文字の一部分への背景色は使わない。
単一区間には通常の文字列書式、複数区間には部分書式、空文字列には空セルを使う。
すべて文字列として書き、先頭ゼロを保持し、数式・URL・数値を自動判定しない。
片側だけの余剰レコード・列もその位置に残す。欠落を理由に行列を詰めない。

## テキスト出力

--textを指定するとExcelのReportを作らず、compareで変更セルだけをconsole::TextReportへ逐次渡す。
標準出力をロックしてWrite経由で出力し、最後のflushまで失敗をResultで呼び出し側へ返す。
全入力・全差分を蓄積しない。読み込み・比較に失敗した場合はfinishを呼ばず、成功の最終集計を出さない。
既に標準出力へ書いた部分の取り消しは行わない。

通常は座標と左右の値を複数行で表示する。--onelineは1差分セル1行。
値はRustの引用符付き文字列表現で制御文字・引用符・バックスラッシュ等をエスケープする。
Noneは<missing>、Some("")は空の引用符付き文字列として区別する。
文字単位の色付けは行わない。成功時は変更セル数と種別別件数、差分なしはNo differences.を表示する。

--addressの既定値はa1。a1は1始まりの列をA〜Z、AA〜へ変換し、論理レコード番号を続ける。
rcはrow=N column=M（両方1始まり）。A1変換を含め、Excelの座標・文字数上限は適用しない。
入力の位置対応・文字コード・終了コードはExcelと共通。
--text時は出力先の検証・作成を行わず、既存diff.xlsxにも触れない。

## 上限と保存

- Excel出力時の入力／出力の座標上限は1,048,576レコード・16,384列。説明用の行列は消費しない。
- 出力するセルは32,767 UTF-16単位を上限とする（補助平面文字は2単位）。
- 変更のないセル、変更前・変更後の各値、差分をまとめた表示文字列のすべてを検査する。
- 旧値と新値がそれぞれ上限内でも、まとめた表示が超える場合はエラーとする。
- 上限超過は位置付きのエラー。切り捨て、勝手なシート分割はしない。
- CSV全体のサイズを固定上限にはせず、最大レコード・差分計算・Excelの制約を受ける。

出力先と同じディレクトリのNamedTempFileへ完成したxlsxを書き、sync後に公開する。
既定はpersist_noclobber。上書きは明示的な`--force`のみ。
出力と入力の同一性はsame-fileで調べ、ハードリンクやシンボリックリンクも保護する。
入力・比較・保存の失敗時に既存出力を置き換えない。
通常終了・エラーでは一時ファイルを破棄する。強制終了・ディスク障害での完全な掃除は保証しない。

## メモリ・ディスク

入力レコード2件と現在の文字差分を保持し、全差分は保持しない。
constant-memoryのワークシートは一時ファイルへ退避するため、ディスクは出力に応じて増える。
巨大な単一レコードや単一セルのメモリまで一定とは限らない。
xlsx生成とZIP圧縮のバッファ・書式・小さなSummaryにもメモリを使う。
同じ書式を再利用し、セルごとのユニークな書式を増やさない。
実測はdocs/validation.mdに記録する。

## CLI

`celldiff LEFT RIGHT [-o FILE] [--force] [--encoding-left ENCODING] [--encoding-right ENCODING]`

`celldiff LEFT RIGHT --text [--oneline] [--address a1|rc]`

`celldiff --list-encodings`

- 比較時は入力2件が必須。-o／--outputは省略でき、カレントディレクトリのdiff.xlsxへ出力する。明示指定時は指定先だけに出力する。出力拡張子は.xlsx。
- 既定出力にも既存ファイル・入力別名の保護、--force、失敗時の既存出力保持を適用する。
- --list-encodings・ヘルプ・バージョン表示では既定出力を生成しない。
- --list-encodingsは入力・出力先なしで対応名と別名を表示し、0で終了する。
- --textは明示的な-o／--output、--force、--list-encodingsと競合する。既定の出力先値は競合扱いにしない。
- --onelineは--textを必要とする。--addressも明示指定時だけ--textを必要とし、既定値a1は通常のExcel実行を妨げない。
- --list-encodingsと--oneline／明示的な--addressは併用不可。不明なaddress値も引数エラー。
- --format・--mode・--summaryは追加しない。
- --encoding-left／--encoding-rightの公開別名は--el／--er。ヘルプに両方を表示する。
- clapがヘルプ、バージョン、引数エラーを生成する。
- 終了コード0:差分なし、1:差分あり、2:実行エラー。
- ヘルプ・バージョン表示は0。
- 標準出力は件数・出力先、標準エラーは実行エラー。
- ヘッダーを特別扱いするオプションは設けない。

## ライブラリと構成

| crate | 用途・理由 |
| --- | --- |
| encoding_rs | 明示指定した文字コードの厳格な逐次変換 |
| csv | CSV構文と順次読み込み、再利用するStringRecord |
| similar（unicode） | 書記素クラスタでの差分、計算時間目安 |
| rust_xlsxwriter（constant_memory） | Rustでxlsx生成、省メモリと部分文字書式 |
| clap（必要なfeatureのみ） | 型付きCLI・ヘルプ・引数検証 |
| tempfile | 一時ワークシート、出力の安全な公開 |
| same-file | OSを跨ぐ同一ファイル判定 |
| zip / roxmltree（テストのみ） | xlsxのZIPとXMLの値・書式を検証 |

単一Cargoパッケージ内でencoding、input、compare、text、output、console、mainに責務を分ける。
Cargo.tomlに依存・配布設定、Cargo.lockに正確な解決バージョンを記録する。
Excel、Git、Pythonは配布exeの実行要件ではない。

## 検証・配布

単体テスト、CLI結合テスト、constant-memory出力のXML検証を3OSで実施する。
配布バイナリでもサンプル比較、上書き保護、差分なしの終了コードを確認する。
性能測定はLinuxで再現可能なCSVを生成し、経過時間・ピークRSS・サンプリングした
一時ファイル＋出力使用量・xlsxサイズを記録する。通常CIとは分けて手動実行する。

配布対象はWindows x86_64（静的CRT）、Linux x86_64-musl、macOS ARM64。
releaseのstrip、thin LTO、codegen-units=1を使い、サイズを実測する。
mainのpush、v*タグ、手動実行でActions成果物を生成する。
自動でGitHub Releaseを公開せず、署名・公証も行わない。
macOSではOS標準ライブラリへ依存する。実際の依存とサイズをcelldiff-build-info.txtに記録する。
